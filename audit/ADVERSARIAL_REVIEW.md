# 对抗式审核报告 · v2（2026-10-12）

**审核目标**：不问“读起来是不是励志”，只问“读者照着做是否有权限、证据、资源和退出路径”。这是一轮项目作者对抗式审阅与自动化测试，**没有冒称是专业律师、人力机构、外部审计或科研团队认证**。

## 评分规则（作者拟定，非科学量表）

每条建议按五项审核：**事实及可追溯性、目标读者适配、授权/法律风险、操作交付完整性、失败替代路径**。出现虚构成果、未授权人事/财务操作或违背法律的建议，直接判为阻断项；其他缺口需要补材料才能公开。所有金额百分比若标为示例，必须注明**虚构教学演示**。

| 对抗情景 | 原建议会错在哪里 | 修复后操作 | 仍有的边界 |
|---|---|---|---|
| 0经验的人看完想直接投VP | 模糊责任与职级差异 | 先检三家目标JD，从一项可授权项目练起 | 某些小公司VP能力结构不同 |
| 工作很忙却一直没升职 | 忙碌≠业务价值或岗位空缺 | 真实证据卡+主管核对+组织机会表 | 公司不承诺晋升 |
| 公司根本没有管理岗位 | 不给机会也怪个人 | 区分个人能力与岗位需求，平行看外部招聘/专家路线 | 换工作有生活与薪资风险 |
| 不喜欢管人的顶级专家 | 强制管理可能害业务和健康 | 双路线岗位对比，允许不选管理 | 各行业专家职位不同 |

| 晋升材料里写“管理30人” | 项目协作≠直属管理 | 明确直属与间接范围、考核权限 | 没权限就如实写没有 |
| 外部高管Title很大但没有授权 | 头衔陷阱与高压问责 | 做Offer尽调、明确预算人事与正式任命 | 合同须个案律师核对 |

| 法定高管有关联交易未申报 | 私人利益与公司利益发生冲突 | 识别关联关系，依章程和公司法走报告及批准程序 | 个案必须由专业机构审核 |
| 法定高管利用公司商业机会 | 忽视忠实、勤勉与利益冲突 | 合规清单、必要披露与批准 | 必须由专业机构评价 |
| 用AI上传组织架构/员工绩效 | 泄露机密或个人信息 | 仅用公开/批准/脱敏资料，人类复核 | 工具数据政策变化快 |
| 低粉项目虚构成功故事营销咨询 | 误导粉丝、侵犯客户权利 | 明确教学假设、真实成果必须有授权 | 不承诺收入或升职 |

| 35岁、职业空窗、换行业 | 从旧Title推断当前竞争力 | 重新看真实JD，靠合法作品与证据 | 外部市场不保证岗位 |
| 对违规要求忍气吞声保晋升 | 重大合规与个人风险 | 合规升级/合法救济，不篡改证据 | 行业法规需另外核验 |

## 按读者完成一次“真实反例”验收

**案例甲：骨干，没有任何下属。** 应能从岗位JD中找到适合试的跨部门Owner项目，凭正式授权练负责能力；项目失败也有止损记录。**不能**在简历上写“管理10人”。

**案例乙：资深经理，业绩稳定但公司没有岗位。** 应能获得“能力/机会分离表”，继续做本职、请求试任并研究外部岗位。**不能**承诺“照着做90天必升VP”。

**案例丙：新入职业务负责人，现金流为负。** 应优先检业务收入与实际回款、质量和合规，不能只做增长汇报。若没有预算权，只能建议而非擅自挪用资金。

**案例丁：被邀请担任法定高管。** 必须核公司章程、正式任命、忠实勤勉与利益冲突义务；必要时找专业人士审核。**不能**仅凭总监Title签署超权限协议。

## 机械校验和人工验收

自动测试检查任务ID唯一、阶段覆盖、来源URL、SOP及模板本地链接、可重现生成、数学边界。浏览器人工/自动冒烟覆盖搜索、阶段切换、完成打勾、能力自评与计划导出。**这些测试不能证明管理方法的因果效果**，无法替代招聘、法律、组织或财务领域的专业个案判断。

**剩余缺口**：跨行业晋升薪酬没有可信统一数值；各公司授权与继任机制可能保密；缺少用户真实长期结果追踪；不应据此生成虚假的成功率。项目应持续根据读者可复核反馈更新。
