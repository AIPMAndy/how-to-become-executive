# SOP 09｜高管不能只负责增长：治理、伦理与法律边界

<!-- EVIDENCE START -->

## 先看原始证据，再决定怎么做

**[EV13｜《公司法》第265条](https://www.samr.gov.cn/xyjgs/flfg/art/2024/art_d4e84936a8a744f8928ac7aec7594345.html)** 中国现行《公司法》第265条对法定高级管理人员有明确界定，公司董事、高管还涉及忠实勤勉、利益冲突等义务。

**因此可以做：**让公司提供正式任命与权限边界；重大利益冲突求助合规或律师。 **但不能推断：**不能看到VP/总监头衔就断定法定身份；法律条文也不代表个案法律意见。

业务“好看”可能隐藏不可逆的代价：客户隐私泄露、违法劳动决策、关联交易、现金挪用或数据造假。本章把治理作为**任职前必须理解的能力**，并非可选的升职技巧。

## 1. 先区分职务头衔与法定高管

我国现行《公司法》第二百六十五条对高级管理人员给出定义，包括经理、副经理、财务负责人、上市公司董事会秘书及章程规定的其他人员。一个人叫“VP/总监”不能仅凭Title推定法定身份，需看任命与章程等资料。

## 2. 三种必须升级的情况

- 可能存在利益冲突、本人或近亲属与公司交易、同业竞争或公司商业机会：**停止个人自行处理**，依据章程向适当治理机构报告并履行批准程序。
- 人力考核、招聘、解雇涉及歧视、个人信息、工伤、劳动特殊保护：经公司HR/法务及合法程序审查，不能只看业务ROI。
- AI自动化处理客户、员工数据：使用经批准的工具、最小化权限，避免把完整简历、薪资、人事记录和机密上传外部模型或公共仓库。

## 3. 决策备忘录必须写一个反对观点

每个重大决策都有“目标、方案、利害关系人、风险、否决条件、负责签字者、复盘日”。邀请持不同意见的同事指出失败方式；但不得要求其提供无权公开的数据。

## 4. 失败处理

发现潜在违规，不擅自销毁材料或自行隐瞒。通过公司合规渠道记录并寻求适当专业建议；必要时采用合法的举报、劳动和监管救济机制。

**完成判据**：岗位身份核对清单、利益冲突清单、责任清晰的决策日志和重大风险升级路径。

**直接法律依据**：[国家市场监督管理总局《公司法》](https://www.samr.gov.cn/xyjgs/flfg/art/2024/art_d4e84936a8a744f8928ac7594345.html)，重点阅读第178—184、265条。
