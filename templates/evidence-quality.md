# 证据质量校验：一页成果卡能经受质询吗？

> 这是一张作者自拟的**核对清单**，不是心理量表。按照真实授权和公司保密规定保存材料。

| 核对问题 | 是/否/不确定 | 我拿得出什么合法证据 |
|---|---|---|
| 是否有清晰业务问题与时间范围？ | | |
| 指标的单位、分母与统计窗口明确？ | | |
| 自己的职责与团队的工作清楚分开？ | | |
| 能证明关键动作确实发生？ | | |
| 结果有业务侧确认或合法汇总记录？ | | |
| 能说出一个合理的替代解释？ | | |
| 负面副作用是否已披露？ | | |
| 是否尊重商业秘密、个人信息和授权？ | | |

**通过门槛（作者建议）**：至少前4项能够实证说明、没有隐瞒重大副作用；涉及数据不能合法展示时，用书面职责/交付摘要替代，承认不足。不要凭勾选数量估算晋升概率。
