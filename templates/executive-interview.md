# 高管/业务负责人面试：六张真实案例卡

每一张都用相同格式：**情境及目标 → 我拥有什么授权 → 可选方案及取舍 → 我具体做了什么 → 结果证据 → 团队贡献 → 如果重做会怎样。**

1. **业务增长或扭转：**你处理过哪些真实客户/收入/交付问题？结果的观察窗口是什么？
2. **失败与纠偏：**做错了什么判断？怎样承认错误、控制损失、修正方案？
3. **战略选择：**面对两个都想做的机会，你凭什么舍弃其中一个？
4. **人才与组织：**你如何授权、招聘、培养或处理岗位能力缺口？是否有正式权限？
5. **跨部门冲突：**双方KPI冲突时如何按事实协商或升级？
6. **合规和伦理：**经营目标与客户权益、员工公平或数据安全冲突时怎么处理？

答不出来就写“目前没有直接经验”，尝试争取实际工作场景，不编造人事权、利润责任或管理人数。
