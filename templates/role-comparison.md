# 管理线 VS 专家线：选择矩阵

| 判断项 | 管理路线 | 专家路线 | 个人偏好与事实 |
|---|---|---|---|
| 最核心的产出 | 团队/业务整体成果 | 复杂专业问题和技术突破 | |
| 人际责任 | 绩效、招聘、冲突、培养 | 影响和协作但可不直管 | |
| 预算与经营风险 | 可能更高，依岗位决定 | 也可很高，依权限决定 | |
| 学习投入 | 战略、财务、人才、组织 | 专业深度、研究与方法创新 | |
| 外部市场 | 实际JD与授权 | 实际专家岗职责 | |
| 家庭与健康负担 | 实际角色强度决定 | 实际角色强度决定 | |

作决定前收集各3份真实JD和真实薪酬区间。不要假设所有管理岗位收入高于专家岗位。
