# 团队与业务运行节奏模板

| 会议 | 频次参考 | 参与方 | 最重要的输出 | 谁负责跟进 |
|---|---|---|---|---|
| 团队周协作 | 每周 | 团队成员 | 阻碍、目标与依赖 | |
| 1对1 | 每两周（按需要调整） | 经理与成员 | 支持、反馈与成长目标 | |
| 业务经营复盘 | 每周或双周 | 指标与财务Owner | 偏差原因及需拍板的两件事 | |
| 资源取舍会 | 按重大变更触发 | 预算授权人 | 预算、风险与停止条件 | |
| 人才与继任 | 每季度（按实际） | HR及主管 | 关键岗位培养与备份 | |

会议规则：**没有待决策事项可改异步更新**；会前提前交材料，会后纪录谁拍板与截止日。避免用会议数量衡量管理能力。
