EV01｜75% 的受薪经理从基层小时工起步

证据的原始结果： 沃尔玛于2026年6月披露：其受薪经理中有75%曾从小时工岗位起步；沃尔玛同时披露培训、学历/技能路径和岗位发展项目。

研究类型与样本：企业自行披露的人才数据。沃尔玛相关受薪管理群体；原文未提供完整因果识别模型

能支持的建议：部分大型企业有真实的内部晋升通道；应查内部选拔规则和管理者培养项目。

不能推出什么：既不能推导一个基层员工有75%概率升经理，也不能推导中国互联网公司采用相同机制。

今天具体做什么：查组织过去12个月内部晋升样例、岗位开放机制和能力标准。

证据评价：中：原始企业披露；对企业自身有说明力，无法外推

原始来源：Walmart Corporate｜沃尔玛2026官方：75%受薪经理从小时工岗位起步（公开时间：2026-06-29；核验：2026-10-12）。

<a id="ev02"></a>

EV02｜企业内部流动高的一组，领导岗位晋升更多

证据的原始结果： LinkedIn 2024企业级观察：内部流动率最高十分位企业的人均管理岗位晋升数量，比最低十分位企业高79%。

研究类型与样本：平台会员职业变动数据的观察研究。企业按内部流动率分十等分；参与企业须至少100次岗位转换且至少5次晋升，具体方法见原文

能支持的建议：研究公司是否提供内部转岗、轮岗、公开竞聘与晋升通道，很有必要。

不能推出什么：相关性，不代表“多参加轮岗可提升79%个人晋升概率”；可能有组织规模、人才质量等混杂变量。

今天具体做什么：询问HR内部岗位公告、轮岗审批、晋升评审和经理支持机制。

证据评价：中：有披露方法；缺少随机分配与因果控制

原始来源：LinkedIn Talent Solutions｜LinkedIn2024：内部流动与领导晋升的企业数据（公开时间：2024-06-24；核验：2026-10-12）。

<a id="ev03"></a>

EV03｜LinkedIn样本中的内部流动率曾上升

证据的原始结果： 2024年LinkedIn对历史样本的分析显示，符合其筛选条件企业的内部流动率由2021年18.7%升至2023年24.4%。

研究类型与样本：平台职业变动数据。企业需至少75次岗位转换；采用企业内部流动率中位数，样本来自LinkedIn会员数据

能支持的建议：职业发展可以考虑横向移动和内部跨职能，不必只等原岗位升职。

不能推出什么：不代表2026年所有企业内部流动率，也不代表内部移动都属于晋升。

今天具体做什么：优先从目标岗位实际需要的相邻职能积累责任和证据。

证据评价：中：限定平台和企业筛选条件

原始来源：LinkedIn Talent Solutions｜LinkedIn2024：2021–2023企业内部流动比例（公开时间：2024-02-22；核验：2026-10-12）。

<a id="ev04"></a>

EV04｜新经理真正困难的不是写计划，而是带人

证据的原始结果： CCL分析近300名参加初任经理领导力项目的新兴领导者，归纳12项挑战，包括管理昔日同事、授权、绩效反馈、冲突和跨组织沟通。

研究类型与样本：培训参与者的组织研究/实务归纳。近300名参加CCL特定培训项目的人员，非随机全球经理代表样本

能支持的建议：从骨干晋升为经理需要专项训练团队与反馈技能。

不能推出什么：不能据此证明12项挑战有统一排序，或每名经理都经历全部挑战。

今天具体做什么：制定新经理30天清单：明确目标、1对1、授权边界、反馈与冲突升级。

证据评价：中：明确样本且与场景直接相关

原始来源：Center for Creative Leadership｜CCL2024：近300名新兴领导者的12类挑战（公开时间：2024-10-25；核验：2026-10-12）。

<a id="ev05"></a>

EV05｜领导力训练是可练习、可迁移的

证据的原始结果： Lacerenza等发表于2017年的元分析整合335个独立样本，领导力培训在学习、迁移和结果等指标上总体有正向效应，效果随设计方式不同而变化。

研究类型与样本：跨研究元分析。335个独立样本；发表在Journal of Applied Psychology

能支持的建议：训练不应只看课程时长，应加入工作实践、反馈和间隔练习。

不能推出什么：培训改善管理学习/绩效指标不等于能够预测高管升职；各研究设计和场景有差异。

今天具体做什么：用真实项目练一个能力，安排30天复盘，检查结果是否迁移到工作。

证据评价：较高：多研究综合，但不针对中国高管晋升

原始来源：Journal of Applied Psychology / PubMed｜Lacerenza等2017：领导力培训335独立样本元分析（公开时间：2017；核验：2026-10-12）。

<a id="ev06"></a>

EV06｜Google研究的关键是团队互动质量

证据的原始结果： Google Project Aristotle分析180个团队（115个工程项目组和65个销售组），识别与团队有效性相关的五个动态因素：心理安全、可靠性、结构清晰、意义与影响。

研究类型与样本：单一大型企业内部团队观察研究。Google 180个团队，团队规模3至50人，中位数9人

能支持的建议：项目Owner要说明目标、角色、决策机制，并让成员能提出风险和问题。

不能推出什么：相关研究，不证明照抄Google会议方式就必然提升KPI；也不等于群体成员素质不重要。

今天具体做什么：在项目章程加入决策权、依赖、责任人、升级与复盘节奏。

证据评价：中：真实企业研究，有环境局限

原始来源：Google re:Work｜Google re:Work：Aristotle 180团队研究（公开时间：公开研究（页面持续更新）；核验：2026-10-12）。

<a id="ev07"></a>

EV07｜当经理也会有压力，不能只看Title

证据的原始结果： Gallup 2026全球职场报告显示：2025年全球经理敬业度22%，非经理为19%；经理敬业度由2022年的31%降至2025年的22%。

研究类型与样本：跨国劳动力抽样调查。Gallup 2026报告：2025年全球调查141444位在职受访者（整体263810）

能支持的建议：转管理岗位要同时评估资源、工作负荷与个人可持续性。

不能推出什么：不是个人升职概率、管理技能等级或“中国经理不快乐的精确比例”。

今天具体做什么：谈晋升时同时核实岗位目标、预算、直接下属数量和资源保障。

证据评价：较高：明确年度调查与方法，仍为主观敬业度指标

原始来源：Gallup｜Gallup2026：2025管理者敬业度22%（公开时间：2026-04；核验：2026-10-12）。

<a id="ev08"></a>

EV08｜经理对团队氛围的作用可以被量化观察

证据的原始结果： Gallup 2015年发表的美国管理研究称，经理因素可以解释团队敬业度评分的约70%方差，并强调频繁沟通、员工发展与优势使用。

研究类型与样本：管理者及员工调查的统计关联。美国职场研究；包含7272名美国成年人等调查，页面另述经理行为调查

能支持的建议：明确期望、持续反馈和成员发展应作为经理核心职责。

不能推出什么：70%是方差解释，不等于经理控制70%的业绩，也不代表因果作用比例。

今天具体做什么：每周明确优先级、对齐责任人，并按月复盘反馈质量。

证据评价：中：关联数据有样本，但易被公众误读

原始来源：Gallup｜Gallup2015：管理者解释团队敬业度评分的显著差异（公开时间：2015-04-08；核验：2026-10-12）。

<a id="ev09"></a>

EV09｜组织是否有继任机制决定了机会是否存在

证据的原始结果： CIPD 2025年继任计划资料指出，继任规划识别未来关键岗位，通常包含与未来职责有关的实践性、定制化工作历练。

研究类型与样本：专业机构证据与实务指南。专业组织知识综述，并非升职概率统计

能支持的建议：职位机会和真实职责体验很重要；争取有授权的试任项目。

不能推出什么：没有证明每家企业都运行正式继任计划；人才储备名单不等于升职承诺。

今天具体做什么：向主管确认岗位窗口、试任职责、评估人和下一次讨论时间。

证据评价：中：专业实务指南，非量化因果研究

原始来源：CIPD｜CIPD2025：继任计划侧重关键岗位与真实工作历练（公开时间：2025-12-05；核验：2026-10-12）。

<a id="ev10"></a>

EV10｜反馈确有作用，也可能起反效果

证据的原始结果： CIPD 2022年对绩效反馈研究进行证据综述：反馈的方式会影响其效果，处理不当可对员工绩效产生不利作用。

研究类型与样本：专业机构证据综述。CIPD回顾研究及实践建议，公开摘要未给单一可外推影响率

能支持的建议：建立以具体行为、共同目标、行动支持为基础的反馈方式。

不能推出什么：不能称一次1对1就能提升X%团队业绩，也不能用反馈取代正式绩效制度。

今天具体做什么：设计“事实—影响—询问—行动—复盘”的1对1记录。

证据评价：中高：综合证据但效果依情境

原始来源：CIPD｜CIPD2022：绩效反馈证据综述（公开时间：2022-09-20；核验：2026-10-12）。

<a id="ev11"></a>

EV11｜高级管理者做的是资源和组织层面的取舍

证据的原始结果： McKinsey 2019年CEO研究使用覆盖70国、24行业、约3500家上市公司和7800位CEO、25年数据的数据库，提出战略、组织、团队、董事会、外部利益相关者及个人效能六大职责。

研究类型与样本：咨询机构历史CEO数据库分析与实务框架。上市公司CEO样本；偏向大型成熟组织

能支持的建议：准备业务负责人时应学习预算、资源取舍、团队搭建与跨组织沟通。

不能推出什么：无法直接推导一个基层员工的七步晋升公式；CEO职责不能原样套到小型团队主管。

今天具体做什么：每月做一页经营复盘：机会、取舍、资源、利润与现金、风险。

证据评价：中：大样本框架，较强的岗位与行业选择偏差

原始来源：McKinsey & Company｜McKinsey2019：基于7800名CEO数据库的六项职责框架（公开时间：2019-10-25；核验：2026-10-12）。

<a id="ev12"></a>

EV12｜真实企业在管理面试看可核验的行为案例

证据的原始结果： 亚马逊官方招聘指导要求申请者结合领导力原则提供以客户、主人翁意识和长期结果为中心的具体经历，并解释自己做过什么。

研究类型与样本：真实雇主公开招聘标准。亚马逊面试指导，非晋升成功率统计

能支持的建议：高管面试应该练习真实决策案例、取舍、冲突与结果，而不是抽象自我评价。

不能推出什么：不能认为所有公司按亚马逊面试，也不能直接套用其页面示例数字当本人经历。

今天具体做什么：准备六张STAR-L案例卡，标明团队贡献和结果的核实方式。

证据评价：高：作为该企业招聘说明可信；外推程度低

原始来源：Amazon官方｜亚马逊2025：领导力原则如何用于面试案例（公开时间：2025；核验：2026-10-12）。

<a id="ev13"></a>

EV13｜高管Title与法定高管身份不能混淆

证据的原始结果： 中国现行《公司法》第265条对法定高级管理人员有明确界定，公司董事、高管还涉及忠实勤勉、利益冲突等义务。

研究类型与样本：现行法律规范。适用依法设立的中国公司，任命与章程细节需要个案核实

能支持的建议：签高管Offer前先核对章程、正式任命、权限和法律责任。

不能推出什么：不能看到VP/总监头衔就断定法定身份；法律条文也不代表个案法律意见。

今天具体做什么：让公司提供正式任命与权限边界；重大利益冲突求助合规或律师。

证据评价：高：直接法律依据，事实适用需核实

原始来源：国家市场监督管理总局｜市场监管总局：《中华人民共和国公司法》（公开时间：2024-07-01；核验：2026-10-12）。

<a id="ev14"></a>

EV14｜经理支持AI时，员工高频使用AI的比例更高

证据的原始结果： Gallup 2026报告援引2026年一季度美国职场调查：在经理积极支持AI使用的群体中，高频使用率79%，缺少这种支持时为46%。

研究类型与样本：美国职场横截面问卷关联。2026 Q1美国就业者调查，尤其涉及已经实施AI的组织

能支持的建议：AI负责人除选工具，还要设计经理示范、培训、流程融合与使用反馈。

不能推出什么：不能据此断言管理者支持AI会因果提升33个百分点，也不代表在中国公司效果相同。
